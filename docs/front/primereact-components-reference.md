# PrimeReact Components Reference

Source: [https://primereact.org/](https://primereact.org/) (v10.9.7)

## Form

* Button — Triggers an action. [https://primereact.org/button/](https://primereact.org/button/)
* InputText — Basic text input. [https://primereact.org/inputtext/](https://primereact.org/inputtext/)
* InputTextarea — Multi-line text input. [https://primereact.org/inputtextarea/](https://primereact.org/inputtextarea/)
* Password — Password input with strength meter. [https://primereact.org/password/](https://primereact.org/password/)
* InputNumber — Numeric input component. [https://primereact.org/inputnumber/](https://primereact.org/inputnumber/)
* Calendar — Date and time picker. [https://primereact.org/calendar/](https://primereact.org/calendar/)
* Checkbox — Boolean checkbox input. [https://primereact.org/checkbox/](https://primereact.org/checkbox/)
* RadioButton — Radio button selection. [https://primereact.org/radiobutton/](https://primereact.org/radiobutton/)
* Dropdown — Select from list. [https://primereact.org/dropdown/](https://primereact.org/dropdown/)
* MultiSelect — Multiple selection dropdown. [https://primereact.org/multiselect/](https://primereact.org/multiselect/)
* AutoComplete — Suggestion input. [https://primereact.org/autocomplete/](https://primereact.org/autocomplete/)
* Chips — Input with tokenized values. [https://primereact.org/chips/](https://primereact.org/chips/)
* Slider — Numeric slider control. [https://primereact.org/slider/](https://primereact.org/slider/)
* Rating — Star rating input. [https://primereact.org/rating/](https://primereact.org/rating/)
* ColorPicker — Pick a color value. [https://primereact.org/colorpicker/](https://primereact.org/colorpicker/)
* ToggleButton — Two state toggle button. [https://primereact.org/togglebutton/](https://primereact.org/togglebutton/)
* SelectButton — Group of selectable buttons. [https://primereact.org/selectbutton/](https://primereact.org/selectbutton/)

* Tree — Tree view component. [https://primereact.org/tree/](https://primereact.org/tree/)
* DataView — Display data in grid or list. [https://primereact.org/dataview/](https://primereact.org/dataview/)
* VirtualScroller — Efficient rendering of large lists. [https://primereact.org/virtualscroller/](https://primereact.org/virtualscroller/)
* Timeline — Visual chronological list. [https://primereact.org/timeline/](https://primereact.org/timeline/)
* OrderList — Reorderable list. [https://primereact.org/orderlist/](https://primereact.org/orderlist/)
* PickList — Dual list transfer component. [https://primereact.org/picklist/](https://primereact.org/picklist/)
* OrganizationChart — Hierarchical organizational chart. [https://primereact.org/organizationchart/](https://primereact.org/organizationchart/)
* Paginator — Pagination component. [https://primereact.org/paginator/](https://primereact.org/paginator/)
